# タンタン（WebTan）

WebページやPDFで見つけた語句を集めて、自分だけの単語帳を作れる学習支援アプリです。

Chrome拡張機能で語句をマークし、Webアプリで説明を追加・整理できます。
登録した語句はカード形式で復習でき、Gemini APIを使った説明文や穴埋め問題の生成にも対応しています。

## 開発背景

WebページやPDFを読みながら学習するとき、気になった語句を別のアプリへ転記し、単語帳にまとめる作業には手間がかかります。

そこで、読んでいる資料から語句を集め、そのまま復習につなげられるアプリを目指しました。

## 主な機能

### Webページ・PDFから語句を収集

- Webページ上で選択した語句をマーカーで強調
- マークした語句を単語カードとして保存
- 専用PDFビューアでローカルのPDFを開き、語句を選択・保存
- マーカーの色とラベルによる単語帳の分類
- ショートカットキーによるマーカーの起動・保存操作

### 単語帳・カードの管理

- 単語帳の作成・削除
- 単語カードの手動追加・削除
- 収集した語句と答えの確認・編集

### 学習・復習

- カードモード・テストモード・編集モードの切り替え
- 答えの表示・非表示
- 学習済み・未学習の管理と絞り込み
- カードのシャッフル
- 問題・解答の印刷

### AIによる学習支援

- 語句に対する簡潔な説明の生成
- 登録した語句を使った文章形式の穴埋め問題と解答の生成

※ AI機能を利用するには、利用者自身のGemini APIキーが必要です。

## セットアップ
詳細は[紹介サイト](https://topaz.dev/projects/3eec3840a5f3336cbd87)をご覧ください。

### 必要なもの

- Google Chrome（PC版）
- Gemini APIキー（AI機能を利用する場合のみ）

### 1. 拡張機能をダウンロード

1. [GitHubリポジトリ](https://github.com/i-nayu/WebTan)を開きます。
2. 「Code」→「Download ZIP」を選択します。
3. ダウンロードしたZIPファイルを展開します。

### 2. Chromeに拡張機能を追加

1. Chromeのアドレスバーに `chrome://extensions/` と入力して開きます。
2. 画面右上の「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選択します。
4. 展開したフォルダ内の `project/public` フォルダを指定します。<img width="679" height="451" alt="image" src="https://github.com/user-attachments/assets/d89732a8-dde3-496f-b129-e1a99ad23079" />

5. 一覧に「タンタン」が追加されたことを確認します。<img width="1512" height="665" alt="image" src="https://github.com/user-attachments/assets/468faa87-fed0-499f-8e47-a13f6ea8f225" />


### 3. ショートカットキーを設定

Chromeで `chrome://extensions/shortcuts` を開き、「タンタン」の次の操作に、それぞれ異なるキーを設定します。

| 操作 | 役割 |
| --- | --- |
| 拡張機能を有効にする | 単語帳やマーカー色の設定画面を開く(任意) |
| 起動/終了 | Webページ上のマーカー機能を切り替える |
| 単語を送信 | マークした語句を保存する |

### 4. Webアプリを開く

[Webアプリを開く](https://tantan-0wp4.onrender.com/)

拡張機能を追加する前から開いていた場合は、ページを再読み込みしてください。

### 5. 語句を集めて学習する

#### Webページから集める

1. 拡張機能の設定画面で、単語帳を作成・選択します。
2. 語句を集めたいWebページを開きます。すでに開いていた場合は再読み込みします。
3. 「起動/終了」のショートカットでマーカーを有効にします。（右上にタンタンのアイコンが表示されます）<img width="1511" height="912" alt="image" src="https://github.com/user-attachments/assets/1a056f6d-0f87-4ab9-bee7-1bc412138237" />

4. 覚えたい語句をドラッグして選択します。<img width="1503" height="862" alt="image" src="https://github.com/user-attachments/assets/991833ed-b2ea-455b-95e5-e5b457eed9b0" />

5. 「単語を送信」のショートカットで保存します。
6. Webアプリで語句を確認し、答えや説明を追加して学習します。<img width="1128" height="861" alt="image" src="https://github.com/user-attachments/assets/c110f6c7-b796-4254-9563-4421c0e43520" />


#### PDFから集める

1. 拡張機能の設定画面からPDFビューアを開きます。
2. 学習したいPDFファイルを読み込みます。
3. 保存先のラベルとマーカー色を設定します。
4. 覚えたい語句を選択し、「マーカーを引く」を押して保存します。
5. Webアプリで保存した語句を確認します。

### AI機能の設定（任意）

AIによる説明や穴埋め問題の生成を利用する場合は、Webアプリの「API設定」から、自分のGemini APIキーを入力して保存してください。

### うまく連携しない場合

- Chromeの拡張機能一覧で「タンタン」が有効になっているか確認してください。
- Webアプリと、語句を集めたいページを再読み込みしてください。
- ショートカットキーがほかの操作と重複していないか確認してください。

## 工夫した点

### 語句の収集から復習までをつなげる構成

Chrome拡張機能が語句の収集を、ReactのWebアプリが整理と学習を担当します。
読んでいるページから語句を取り込み、単語帳として利用できる構成にしました。

### 色とラベルで単語帳を分類

単語帳にマーカー色とラベルを持たせ、収集時に保存先を選べるようにしました。
学習分野や目的に合わせて、語句を視覚的に整理できます。

### 学習状況に応じた復習

カードに学習済みの状態を持たせ、未学習の語句だけを表示できるようにしました。
シャッフル機能と組み合わせて、覚えたい語句を繰り返し確認できます。

### AIを使った教材作成

語句の説明だけでなく、複数の語句を使った穴埋め問題も生成できます。
単語単体の暗記に加え、文章の中で意味を確認する学習を目指しました。

## 技術選定の理由

- **React**  
  単語帳一覧・カード学習・語句確認などの画面を、状態に応じて更新するために採用しました。

- **TypeScript**  
  単語帳や単語カードのデータ構造を型で表し、扱う情報を明確にするために採用しました。

- **Vite**  
  ReactとTypeScriptの開発環境を用意し、開発サーバーとビルドをまとめて扱うために採用しました。

- **Chrome Extensions / Chrome Storage API**  
  閲覧中のページ上で語句を選択し、拡張機能内に保存するために採用しました。

- **PDF.js**  
  PDFをブラウザ上に描画し、テキストを選択できる学習用ビューアを実装するために採用しました。

- **Gemini API**  
  語句の説明や、登録した語句に合わせた学習問題を生成するために採用しました。
